Mezzano Listener and Debugger

Return executes input through the guest Command Processor. Alphabetic input names a command or known variable. Other input is Lisp. A leading comma forces Lisp. Shift-Return inserts a newline. One Listener job runs at a time in this session.

SPACE completes a command word. Tab or COMPLETE completes a token. F12 or Ctrl-? requests contextual help. The guest supplies argument prompts and defaults. This editor displays prompts above the input rather than interleaved within it.

Ctrl-Meta-Y recalls the latest accepted input. Meta-Y recalls earlier input. Escape or Input History displays accepted input. Recall fills the editor. Return executes recalled input as a new request. F10 clears input.

Pathnames in command output are mouse-sensitive. Mouse-Left inserts a pathname into the expected pathname argument. Return executes the completed command.

Mouse-Right opens the System Menu. The bottom activity label also opens it.

Evaluations retains output and values in the machine. An interactive evaluation waits for supplied input or EOF. Release removes a completed evaluation's storage.

Debugger lists retained stops. Select a stop, inspect its condition, frames, and locals, or invoke an available zero-argument restart. A printer can enter a child stop. Typed commands include :Show Backtrace, :Show Proceed Options, :Set Current Frame N, :Show Frame, and :Show Local All. Original caller arguments remain unavailable.

Requests keeps submissions whose replies were lost. Repeating a recorded request uses its original name, range, or ID. An expired session requires a new session.

The clock shows browser time. Printed values are text. Public binding writes, frame evaluation, object browsing, and stepping remain under development.

Recovered Symbolics font rasters pass Chromium DPR1 tests. Whole-screen fidelity remains under review.

Mouse-Right: System Menu. Return: Execute input. Tab: Complete. F12: Help.
