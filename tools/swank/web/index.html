Mezzano Listener and Debugger

F9 starts SELECT. L selects the Listener, D selects Document Examiner, and P selects Peek. F9 then F12 lists these activities. Backspace cancels SELECT without changing input.

Return or Shift-F11 executes input through the guest Command Processor. Alphabetic input or an initial colon introduces a command. A bound variable name is accepted when it does not name a command. Other input is Lisp. A leading comma forces Lisp. Shift-Return inserts a newline. Ordinary Listener submissions run one at a time in this session.

SPACE completes a command word. Tab or F11 completes a name. F12 or Ctrl-? requests contextual help. Another SPACE accepts a displayed argument default. The guest supplies argument prompts and defaults. Argument prompts and contextual help appear above the input.

Ctrl-Alt-Y recalls the latest accepted Listener input. Alt-Y recalls earlier input. Escape or Input History displays accepted input. Recall fills the editor. Return executes recalled input as a new request. F10 clears input.

Pathnames in command output are mouse-sensitive. Mouse-Left inserts a pathname into the expected pathname argument. Return executes the completed command.

Mouse-Right opens the System Menu. The bottom activity label also opens it.

Evaluations retains output and values in the machine. An interactive evaluation waits for supplied input or EOF. Release removes a completed evaluation's storage. Clear All terminates retained evaluations across Listeners, releases their data and closed debugger records, and clears this tab's evaluation histories. Its own result remains in Evaluations for request recovery. Document viewers and bookmarks remain stored. Clear Output History clears the displayed transcript while preserving input history and retained evaluations.

A stopped Listener directs input to its innermost debugger. Each level preserves its draft and cursor. :Abort leaves that level, and :Help displays guest command help. Debugger lists retained stops. Select a stop, inspect its condition, frames, and locals, or invoke a restart interactively. Restart argument readers use the evaluation's input controls. Interrupt requests a stop in a running evaluation. A printer can enter a child stop. Parent Stop and Child Stop navigate those stops. Typed commands include :Show Backtrace, :Show Proceed Options, :Set Current Frame N, :Show Frame, :Show Local N, and :Show Local All. Queried results remain available after a stop closes, until Release Stop. Original caller arguments remain unavailable.

Requests keeps submissions whose replies were lost. Repeating a recorded request uses its original name, range, or ID. After an explicit expired-session response, the browser creates a new session, archives prior requests, and refreshes the current activity. Archived requests retain their original identity and cannot replay in the new session. Connect / Resume preserves the session after a transport failure.

The clock shows browser time. Printed values are text. Binding writes, frame evaluation, object browsing, and stepping are unavailable in this interface.

Document Examiner contains the installation, Command Processor, debugger, and documentation guides.

Mouse-Right: System Menu. Return: Execute input. Tab: Complete. F12: Help.
